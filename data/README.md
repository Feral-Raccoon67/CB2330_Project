# Data

The data used in this project were taken from *Table 2* in Llopart et al. (2025), *A high-resolution crossover landscape in Drosophila santomea reveals rapid and concerted evolution of multiple properties of crossing over control*.

The table contains the number of meiotic events with different numbers of crossovers for five chromosome arms: 2L, 2R, 3L, 3R and X.

## Data shape

The dataset contains 5 crossover classes and 5 chromosome arms where NCO represents 0 crossovers, 1CO represents 1 crossover, 2CO represents 2 crossovers, 3CO represents 3 crossovers and 4CO represents 4 crossovers.

The columns are Chromosome Class, 2L, 2R, 3L, 3R and X where columns 2L, 2R, 3L, 3R and X represent the chromosome arms. Each value gives the number of observed meiotic events belonging to that crossover class for the corresponding chromosome arm.

The `Total` row gives the total number of observed meiotic events for each chromosome arm.

The data is stored in `Crossover_data.xlsx`.
